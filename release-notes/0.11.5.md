## What's new

- **Skill shipped with the plugin.** Chart Hands now includes a "Data insights and charts" Skill, in Korean and English, for AI hosts that read plugin Skills (Verbex, latest version). It guides the agent from a spreadsheet or table to evidence-based insights and report-ready charts, using the `eda_profile`, `eda_analyze`, `suggest_chart`, `build_chart` and `check_chart` tools.
- **Settings tab shows Skill support.** The settings tab now tells you whether an enabled AI host can read this plugin's Skills, and what to do if none can.

The tools are unchanged, so older AI hosts keep working. As after every update, Verbex asks you to approve Chart Hands again before the agent can use its tools.
