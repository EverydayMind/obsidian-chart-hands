## What's new

- **Charts from wide and long tables.** `build_chart` and `eda_analyze` take two new analysis sources: `summary` gives one value or share per column (for example export shares by country when each country is a column), and `pivot` turns a long table into a grid (heatmap) or one series per category (stacked bars). The numbers still come from the tools, not from the model. In a count pivot, a combination with no rows is 0.
- **Gauges with a target.** An `indicator` can be drawn as a gauge (`gauge: true`) with a `target` threshold, from a `summary` value. Percentage gaps are shown in %p, matching the fact line.
- **Charts already in a note.** `read_charts` can compare one chart with its source data and list the values that differ (`compare`). Charts built by `build_chart` now keep their build recipe in a second comment line, so `read_charts` returns `rebuild` and the line range of the chart with its fact lines (`snippet`) to redraw it from updated data. `build_chart` with `from_chart` restyles an existing chart (report, print or slides style, a target line, title, caption) without changing its data, even a hand-written one.
- **Easier fixes.** When a block does not parse, `check_chart` now also points at likely causes line by line (an unquoted colour, a stray top-level key, tabs). An empty `fit: {}` no longer stops a chart from drawing.
- **Better reading of requests.** `suggest_chart` understands chart forms ("stacked bars", "bars and a line", "donut", "heatmap"), columns named in the request, order words ("largest first", "the five lowest"), a single value to filter on (such as `2026-W45`), and offers up to three overview candidates when no goal is given.
- **Smaller things.** Scatter and bubble points are named from `source.labels`; with a source, `series[].text` must give one name per point, and a shorter list is refused with a pointer to `source.labels` instead of labelling only the first point. Sorting by a period column is chronological. Ranked horizontal bars put the first item on top. Values keep the decimals of the data (172.4 instead of 172). Pivot charts are written as readable YAML unless they are very large. Errors name the argument to fix and show an example with the file's own column names, `source.x` on a bar or line chart is read as the category column, and a file name without a folder is found when only one file has that name.
- **Guide and Skill.** `get_chart_guide` with `dataviewjs` starts with the current state of Dataview and its JavaScript queries, and gives an example that counts notes by a property. The "Data insights and charts" Skill now covers charts already in notes, charts of vault notes, live charts and HWPX documents.

Charts in your notes are unchanged. A block built by this version has one more comment line, which earlier versions ignore. The tool definitions changed, so Verbex asks you to approve Chart Hands again before the agent can use its tools (as after every update). Verbex 0.3.1 recommends this version for the data and chart Skill; earlier Verbex versions work with it too.
