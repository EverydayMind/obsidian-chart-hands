## What's new

- **Chart blocks stay intact.** The "New Plotly chart" commands keep the code fence on its own lines, so inserting mid-sentence or above a heading no longer breaks the chart.
- **Dataview check.** The Dataviewjs command tells you when Dataview is not enabled.
- **Right-click menu.** "Insert Plotly chart" is in the editor right-click menu.
- **Settings.** The settings tab starts with how to add a chart.
